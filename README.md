# Ingenii React Dashboard

React + TypeScript + Vite + Tailwind CSS + lucide-react recreation of the supplied Ingenii Figma screens.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Screens

- Get Started / landing
- Solution Builder
- Dashboard / Home
- Source module
- Shared module layout for Curate, Annotate, Train, Secure, Deploy and Govern

## Navigation

The UI uses hash routes so page state is explicit and survives refresh:

- `#/get-started`
- `#/solution`
- `#/dashboard`
- `#/source`
- `#/curate`
- `#/annotate`
- `#/train`
- `#/secure`
- `#/deploy`
- `#/govern`

Get Started and Dashboard are separate screens by design.
